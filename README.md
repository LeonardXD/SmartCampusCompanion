# Smart Campus Companion

## App Description

Smart Campus Companion is an Android mobile application designed to support university students by providing campus information, academic task and schedule management, campus announcements, and personalized app settings.

### Git Workflow

1. Create and use a remote GitHub repository.
2. Maintain `main` and `develop` branches.
3. Create feature branches from `develop` for individual tasks.
4. Commit early and often with meaningful commit messages (minimum 5 commits per member).
5. Open pull requests to merge feature branches into `develop`, then merge stable work into `main`.
6. Review changes before merging and resolve conflicts collaboratively.
