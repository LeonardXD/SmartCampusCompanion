# Smart Campus Companion

This is an Android application for the Smart Campus Companion project.

## Team Roles

*   **Team Lead:** Responsible for overall project management, coordination, and final decisions.
*   **Frontend Developer:** Responsible for implementing the user interface and user experience.
*   **Backend Developer:** Responsible for managing data, and business logic.
*   **QA Engineer:** Responsible for testing, quality assurance, and bug reporting.
*   **UI/UX Designer:** Responsible for designing the application's look and feel.

## Development Workflow

1.  **Feature Assignment:** Features are assigned to developers from the project backlog.
2.  **Branching:** Create a new feature branch from the `main` branch for each new feature (e.g., `feature/campus-info`).
3.  **Implementation:** Implement the feature on the feature branch.
4.  **Testing:** Write and run unit and integration tests for the feature.
5.  **Pull Request:** Create a pull request to merge the feature branch into the `main` branch.
6.  **Code Review:** At least one other team member must review and approve the pull request.
7.  **Merge:** Once approved, the pull request is merged into the `main` branch.
