# Manual Testing Checklist

## Login
- [ ] Test with correct credentials, should succeed and navigate to dashboard.
- [ ] Test with incorrect credentials, should show an error message.
- [ ] Test remember me functionality.

## Dashboard
- [ ] Verify that the dashboard screen displays correctly after login.
- [ ] Test navigation to the Campus Info screen.

## Campus Info
- [ ] Verify that the list of departments is displayed correctly.
- [ ] Verify that all department details (name, description, email, phone) are visible.
